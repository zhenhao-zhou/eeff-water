# Code and data availability

The modified LAMMPS source files, final EeFF-water parameter set, parameterization dataset, representative simulation inputs, and processed numerical source data included with this release are available in this repository:

https://github.com/zhenhao-zhou/eeff-water

Complete molecular-dynamics trajectories are not included because of their size. Details of the model formulation, simulation protocols, and analysis definitions are provided in the manuscript and Supporting Information.
