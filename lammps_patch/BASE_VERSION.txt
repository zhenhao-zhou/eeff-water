LAMMPS base version
===================

Base release used for the archived EeFF-water source modifications:
    LAMMPS (2 Aug 2023 - Update 3)

Upstream source identifier:
    The exact upstream Git commit was not retained in the archived build metadata.
    Use the official 2 Aug 2023 - Update 3 source release as the base tree.

Recorded build environment:
    Operating system: KOS 5.8
    GCC/G++: 8.5.0
    OpenMPI: 4.1.6
    Build system: legacy LAMMPS make workflow

Packages required by the representative examples:
    EFF
    MOLECULE
    EXTRA-FIX   (for fix temp/csvr)

Additional packages that were enabled in the original production build:
    EXTRA-DUMP, KSPACE, MANYBODY, REAXFF, RIGID

The files in ../src/ are intended to replace files with the same names in a clean
LAMMPS 2 Aug 2023 - Update 3 source tree. Files not included in ../src/ must be
taken unchanged from that base release.
